# Collision for buildings, trees, containers (and more)

Not tested in the Godot editor. Open the project once, then check the Output panel. `main.tscn` now has about 320
collision shapes, so the first load takes a moment longer.

## What is solid now
Found by analysing the background image and checked on overlays (`tools/previews/obstacles_final.png` is drawn from the
shapes that are actually in `main.tscn`):

| Node in main.tscn | Count | What |
|---|---|---|
| `Houses` | 56 | the residential houses (done earlier) |
| `Buildings` | 113 | towers and helipad buildings, shops, the red/white store, the gray panel buildings, warehouses, factories, garages, rooftop-sized crates, park benches, the station and its kiosks, the four railway platform canopies |
| `Containers` | 19 | the container yards: each row of containers is one solid band (the gaps between rows are about 8 px, too narrow to walk through) |
| `Silos` | 29 | silos, round tanks, the two fountains |
| `Trees` | 105 | residential gardens, the park, parking-lot and station plaza trees |

- **Trees:** the collision circle is 80 % of the visible canopy, so you can brush past the leaves.
- **Not included:** the trains and tracks, the footbridge over the tracks, tiny shrubs and bushes (5 px).
- Everything is a normal editor shape: select a node under `Buildings` / `Trees` / ... and move or resize it. If you
  re-run `tools/apply_obstacles.py` it REPLACES the four generated groups (Buildings, Containers, Silos, Trees), so do
  hand edits afterwards or keep a copy.

## What they affect
- **Player and enemies** collide with them; projectiles stop at them: AK-47 bullets (with sparks), rockets (they explode),
  thrown bottles (they shatter) and enemy shoes.
- **Out of bounds:** anything whose center ends up INSIDE any of these shapes (teleport target, ghost knockback through a
  wall, a bad spawn) is sent to (0, 0). If a point is blocked, the nearest free spot is used instead, so this can never loop.
  Teleporting (Q) into any obstacle is refused with the "Can't teleport into a house" hint (the player's body size is
  included), enemies and drops never spawn inside them.
- **World (0, 0) is plain asphalt at a road intersection**, so it is free. I need to correct my earlier docs here: I had
  written that it lies on a shop roof, which was a mistake from a scaling mix-up. The player's start is free too.
- **Enemies have no pathfinding** (they steer straight at the player and slide along walls), so big buildings can hold them
  up. The unstick behaviour was strengthened: an enemy that is blocked again soon after sidestepping keeps going around
  the same way, for longer (up to 3 s).
- **Performance:** `world/house_colliders.gd` uses a lookup grid, so checking whether a point is inside an obstacle
  stays fast with hundreds of shapes (checked against brute force on 60,000 random points, no mismatches). About a quarter of the
  map area is now solid obstacle.

## Re-generating (e.g. after changing the background art)
1. `python3 tools/detect_obstacles.py` writes `tools/obstacles.json` and a preview overlay.
2. `python3 tools/apply_obstacles.py` writes the shapes into `main.tscn`.
Close the project in the editor first, or reload the scene afterwards. The houses were generated by an earlier, separate script.
